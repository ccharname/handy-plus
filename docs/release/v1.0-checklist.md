# v1.0.0 Release Checklist

Human e2e verification. All boxes must be checked before `git tag v1.0.0`.

## Preset Switching

- [ ] **Dual preset visible**: Settings > ASR Presets shows exactly two cards — "Chinese Balanced" and "Qwen3-ASR Realtime". No legacy presets (Apple Speech, Voxtral, Multilingual Offline, experimental Qwen3).
- [ ] **Switch to chinese_balanced**: Select Chinese Balanced, click Apply. Active badge appears, next recording uses SenseVoice.
- [ ] **Switch to qwen3_mlx**: Select Qwen3-ASR Realtime, click Apply (or Download & Apply if model not present). Active badge appears. App gate enforces Apple Silicon — verify Intel Mac or Linux shows only Chinese Balanced.
- [ ] **Settings persist across restart**: Switch preset, quit app, relaunch, confirm selected preset is retained.

## Chinese Recognition (chinese_balanced)

- [ ] **Short phrase (< 3s)**: Record "今天天气怎么样" — ITN + punctuation correct, pasted to active app.
- [ ] **Long recording (> 20s)**: Sustained Chinese speech — transcript complete, no duplicate sentences, reasonable RTF (check `handy-logs.sh percentiles --stage t5_inference --preset chinese_balanced`).
- [ ] **Hotword injection**: Add a custom hotword (e.g. "OpenAI"), verify it appears correctly in transcript.

## English & Multilingual (qwen3_mlx)

- [ ] **English recognition**: Record 10s of English speech with qwen3_mlx active — transcript accurate, overlay shows streaming tokens.
- [ ] **Overlay streaming**: Overlay window appears during recording and shows tokens appearing as inference progresses.

## Cancel Race

- [ ] **Cancel during recording**: Start recording, immediately press cancel shortcut — recording stops, NO text is pasted to active app. Outcome = cancelled in handy-logs.
- [ ] **Cancel during inference**: Record 5s, release hotkey to trigger inference, press cancel within 500ms — inference is discarded, nothing pasted.

## Overlay Window

- [ ] **Overlay appears on recording start**: Overlay window visible and correctly positioned on primary display.
- [ ] **Overlay dismisses on completion**: After transcript is pasted, overlay closes cleanly (no lingering ghost window).
- [ ] **Overlay dismisses on cancel**: Pressing cancel closes overlay immediately.

## Hotkey Response

- [ ] **Default hotkey works**: Push-to-talk with default shortcut triggers recording (audio indicator / overlay shows).
- [ ] **Hotkey customization**: Change shortcut in Settings, new shortcut triggers recording, old one does nothing.
- [ ] **No double-trigger**: Holding hotkey for 5s produces one recording session (not multiple).

## Settings Persistence

- [ ] **Migration v_0_8_17 runs cleanly**: If upgrading from a pre-1.0 build that had a legacy preset stored (e.g. `apple_native`), the stored preset resets to `chinese_balanced` on first launch. No crash, no stuck "Unknown preset" state.
- [ ] **Cross-restart data retention**: Custom hotwords, selected preset, audio device selection — all retained after quit and relaunch.

## Performance SLA (requires >= 7 days usage data)

- [ ] **SLA hard gates pass**: Run `bash scripts/release-check.sh` and confirm all `handy-logs assert` gates show PASS (not just SKIP). Minimum 30 samples per stage required.

## Build Integrity

- [ ] **release-check.sh passes**: `bash scripts/release-check.sh` exits 0 (FAIL=0). Includes lint + clippy + tests + SLA gates + build + codesign.
- [ ] **App signed**: `codesign -dv /Applications/Handy.app 2>&1 | grep Authority=` shows signing identity.
